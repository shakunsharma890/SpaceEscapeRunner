# SpaceEscapeRunner 🚀

A modern, fast-paced side-scrolling space evasion game built with **React Native** and **Expo**.

## 🎮 Gameplay
- **Objective:** Navigate your spaceship to dodge incoming asteroids.
- **Controls:** Use the "Left" and "Right" buttons to move your ship.
- **Goal:** Survive as long as possible and beat your High Score!

## ✨ Key Features
- **Smooth Animations:** Optimized game loop for fluid movement.
- **Persistence:** High scores are saved locally using `@react-native-async-storage/async-storage`.
- **Modern UI:** Features a sleek "glassmorphism" aesthetic with a deep-space gradient background.
- **Custom Design:** Spaceship and asteroids built using pure React Native view components.

## 🛠 Tech Stack
- **Framework:** React Native / Expo
- **Language:** JavaScript
- **Storage:** AsyncStorage
- **Styling:** LinearGradient
